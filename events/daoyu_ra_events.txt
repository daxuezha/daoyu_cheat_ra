###############################################################################
# Daoyu Cheat - Real History Compatibility
# 本补丁新增的事件文件（新文件，不覆盖基础 Mod 或原版任何事件）
#
# 事件 ID：daoyu.292（基础 Mod 未占用；.290 / .291 已被占用）
#
# 用途：为**单个**角色指定其可以参加的政治运动。
#
# 作用域约定：
#   本事件为 country_event，this = 玩家国。
#   目标角色由玩家国的变量 daoyu_ra_mv_character 传入，在 immediate 中解析为
#   scope:daoyu_target_character。分页重开事件时该变量保留，因此翻页不会丢目标。
#
# 【重要】为什么只改目标角色的意识形态
#   引擎没有「把角色指派到政治运动」的接口，角色的运动归属由引擎按
#   common/political_movements/*.txt 里的 character_support_trigger 自动判定。
#   所以本菜单的做法是：
#     1) 在目标国创建该类型的运动（已存在则直接沿用）；
#     2) 只把**目标角色**的意识形态改成该运动 character_support_trigger 所认可的
#        那一个 —— 见脚本效果 daoyu_ra_mv_apply_ideology_effect。
#   绝不批量修改角色意识形态，否则会把本国其他角色一起卷进该运动。
#
# 分页：45 种运动，每页 15 种，共 3 页。
#   结构与基础 Mod 的意识形态菜单（daoyu.250）保持一致：
#     · 「上一页」放在列表最前面，第 1 页时不显示；
#     · 「下一页」放在列表最后面，第 3 页时不显示；
#     · 「退出」只有一个，用原版已有的 RESIGN；
#   翻页由脚本效果 daoyu_ra_mv_page_prev / _next 移动页标记后重开本事件实现。
#
# 【易错提醒】选项的显示条件必须写 trigger，不能写成 ai_chance。
#   曾经误把 ai_chance = { base = 100 } 当显示条件，导致「退出」在每页都渲染、
#   出现三个退出按钮，且点到假按钮时只清了页标记却不关界面。
###############################################################################
