# Daoyu Cheat - Real History Compatibility
# 本补丁新增的事件文件（新文件，不覆盖基础 Mod 或原版任何事件）
#
# 事件 ID：daoyu.292（基础 Mod 未占用；.290 / .291 已被占用）
#
# 用途：为鼓动者指定其可以参加的政治运动。
#
# 引擎能力边界（本功能的设计依据）：
#   引擎不存在「把角色指派到某个政治运动」的脚本效果。可用命令只有
#   create_political_movement / bolster_political_movement / suppress_political_movement，
#   全部以国家为作用域；角色侧只有只读的 character_supports_political_movement。
#   角色的运动归属由引擎按 political_movements 定义中的 character_support_trigger 自动判定。
#
#   因此本菜单提供两种做法：
#     1)「自动匹配」：按角色当前意识形态，在其所属国创建相配的运动；
#     2)「手动指定」：直接选定运动类型创建，角色可参加的运动随之确定。
#   两者都让目标国出现与角色相配的运动，角色即会自动参加 / 支持它。
#
# 作用域说明：
#   本事件为 country_event，触发者即玩家国；this = 玩家国。
#   角色由国家变量 daoyu_ra_mv_target 传入，在 immediate 中解析为
#   scope:daoyu_target_character（与基础 Mod 其他菜单保持一致）。
###############################################################################
